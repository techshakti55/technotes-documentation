# TechNotes Documentation

Central engineering documentation repository for **technotes.co.in**.

This repository will be the source of truth for architecture, team processes, development standards, DevOps, API standards, deployment procedures, and Architecture Decision Records (ADRs).

## Engineering Workflow

`feature branch -> pull request -> review -> merge`

## Platform Baseline

- Java 21
- Spring Boot 3.5.x
- Microservices
- Eureka
- Spring Cloud Config Server
- MongoDB
- MinIO for local object storage
- Elasticsearch
- HTML/CSS/JavaScript for Phase 1
- Docker / Docker Compose
- AWS EC2 initial production-like deployment
