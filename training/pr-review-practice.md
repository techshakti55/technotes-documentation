# Pull Request Review Practice

This file exists only to practice the TechNotes pull request workflow.

## Objective

Learn how to review a pull request before merging it.

## Review Checklist

- Read the PR summary in Conversation.
- Check all commits in the Commits tab.
- Inspect exact additions and deletions in Files changed.
- Confirm there are no secrets or accidental files.
- Leave comments when something is unclear.
- Approve only after the change is understood.
- Merge only into the intended base branch.
